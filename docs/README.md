# docs/ 索引

> 全仓**唯一的文档索引**。想知道「哪件事该看哪篇」就看这里；想知道「改了代码该跑什么」用 `bash tools/run_tests.sh --changed`（自动映射，不必读文档）。

## 这个项目是什么

AI Project Lab：面向青少年（8–18 岁）的 AI Agent 教育产品，交付标准对齐 CCF LMCC-T 认证（青少年组）。demo 已完工（2026-09-14 验收），此后完成世界度量体系 v2 与模块化改造。
