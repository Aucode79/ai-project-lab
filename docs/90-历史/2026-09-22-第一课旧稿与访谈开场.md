## 2026-09-22 重设计：先介绍 Agent 是什么

### 本轮已确认的方向

- **定位**：第一课偏介绍，首要目标是让学生产生“我也想搭一个 Agent”的兴趣。先回答“Agent 是什么”，再展示它能做什么，不先考核循环原理。
- **主任务**：学生通过已有对话框提出运输目标；Agent 开始运输后，现场封住原路，由它观察变化、决定改道。实际行动和结果须有真实运行记录，不能事先写定成功路径。
- **呈现**：Agent、内部组件与运输现场在同一个沙盒世界里，全程对应展示。旁白讲观察、决定、行动及结果，不点名讲解内部部件，不另造分屏控制室或内部小窗。
- **扩展**：运输完成后，预留约 15–20 秒展示同一个 Agent 接受整理散落方块的新任务。该段也需真实记录，不能以动画补出尚未实现的能力。
- **课后**：学生通过现有对话框给现成 Agent 派一次任务，再进入后续搭建课程。三题练习是否保留及解锁规则尚未重定，不把旧版三题放在这次亲手体验之前。

### 后半段衔接与待验证范围

开场之后接：真实运输开始 → 现场封路 → Agent 取得变化信息 → 根据返回结果选择行动 → 检查运输结果。通过验证后，再写这些段落的旁白、机位和秒位；若未能改道送达，保留失败记录并继续修实现，不剪成已成功。

## 0. 定位与学习目标

- 时长 5 分钟。形式：对标乐乐课堂「天天练」结构——一集一个知识点、纯线性动画视频（本课 5 分钟，落在 3–5 分钟档）、视频后配三道阶梯练习、招式总结句收尾、三星标记单课完成度（参考：[天天练官方介绍](https://www.leleketang.com/download/index.php)与仓内竞品调研 `research/lmcc/raw/H-国内K12教育App交互.md`）。用一个任务贯穿全片，**整课按悬念链推进（v7）：每段结尾埋一个问题、下一段开场第一句接住，链头 10 秒内甩出真任务**。**镜头节奏**另对标乐乐课堂《新概念英语青少版》1B/3B 实测（2026-09-19 调研，见 §3.0 与 §6）：正片每 3–9 秒一次画面变化，本课全程 39 镜头、镜头长 3–12 秒、多数 5–10 秒（最短课题卡；最长为逐行回传＋思考窗、点数＋小结、失败真演三处 12s；「持续变化型」长镜内部每 2–3 秒有一次变化）。**旁白语体**（v5）对标乐乐课堂高中课三集实测（2026-09-20 调研；语体规范①–⑦的真源自 2026-09-20 起外提至《[课程设计规范](../50-课程/课程设计规范.md)》§二，原 §3.0 所载即其出处），本课程线后续各课共用。
- **主受众＝高中档（视频旁白）**；§4 分层挑战题的 8–11 / 12–14 岁两档为选做加宽，主线三题全年龄通用。
- 核心知识点：**Agent 会根据执行结果，决定下一步行动。**
- 本课目的：先让学生看懂一次完整运行——Agent 拿到一个目标，怎么自己想办法一步一步把活干完；看懂了这次运行，自然生出「原来它是这样做事的，我也能搭一个」的念头。课程主线是——**先看懂总体运行**，部件怎么拆、怎么搭，留给第二课；不是「AI 使用技巧课」。

课后学生应能回答：

| 问题 | 答案 |
|---|---|
| 下一步行动谁提出？ | 它自己——看完上一步的结果，再想下一步 |
| 谁真正读取、修改文件？ | 还是它自己：读文件、写文件，一步一个动作 |
| 结果返回后，为什么还要看？ | 好据此决定继续做什么，或者结束 |

## 1. 贯穿任务（沿用 L2 已有样例）

> **数出报告中「错误」出现了几次，把数量写进结果文件。**

样例真源（不新造文件）：

- 任务原文 = L2 任务一：`game/scripts/levels/l2/l2_flow.gd:35`（「读 report.txt，数出『错误』出现的次数，把结果写进 out.txt 格」）

report.txt 全文（「错误」出现 **3 次**，全部独立出现，在第 2、3、4 行）：

```text
第 1 行 模块A 启动正常
第 2 行 模块B 报告 错误：超时
第 3 行 模块B 报告 错误：重试后成功
第 4 行 模块C 数据校验 错误：校验和不匹配
第 5 行 模块C 自检通过
```

（L3 另有一份部署日志版报告 `game/scripts/levels/l3/l3_flow.gd:36`，也是 3 次；本课画面用 L2 版，它的任务语义与「数错误、写结果文件」完全一致。）

画面显示「报告」和「结果文件」两个面板，小字保留文件名 report.txt / out.txt；学生不需要先学文件扩展名。

这个例子的价值：**交付物是实际写入的文件**，学生可以清楚区分「说要写」「执行写入」和「检查写入结果」。

## 4. 视频后练习题组（一个视频配三道题）

对标天天练「视频播完 → 三道阶梯练习 → 答完解锁下一节」（仓内调研 `research/lmcc/raw/H-国内K12教育App交互.md:28-34,39,431`）。三题主线全年龄通用、逐题递进；每题即时判分、带错因与**重看锚点**（跳回视频对应时间点——天天练缺这个入口、被用户批评，见 `H-国内K12教育App交互.md:45-46`，本课主动补上）；单课完成度用三星标记，三题全对点亮并解锁下一课。主体保持直观，不要求记英文名。

**题 1 · 复述认循环**（重看锚点 3:00，段6 起点）
它每干完一步，接下来会做什么？
- A. 直接宣布任务完成
- B. 先看看刚才那步的结果，再定下一步
- C. 按写死的顺序一路走到底

答案 B。错因：A 没等结果就收工——万一这步没成，后面全是白搭；C 是预设流程，不管结果照走，跟「看着结果定下一步」正好相反。

**题 2 · 应用失败分支**（重看锚点 3:40，段7 起点）
写入返回「写入失败：没有权限」，下一步应该怎么做？
- A. 宣布任务完成
- B. 根据错误决定怎么办；解决不了就说明哪里受阻
- C. 不看返回结果，继续做下一步

答案 B。错因：A 和 C 都没把「实际发生的事」接回决策——按 4:16 的三段式小结图：失败后先想办法，不行就说明哪里受阻；看到失败还宣布完成，就是行动和结果没接上。

**题 3 · 辨析概念边界**（重看锚点 3:10，段6 双机对照动画）
哪种情况说明 Agent 真的在「根据结果决定下一步」？
- A. 三步按固定顺序播放，不管每步结果是什么都照走
- B. 写入失败后，不再硬写，改为说明哪里受阻

答案 B。错因：固定顺序照走 = 预设流程，不是自主决策；看见失败改变行动，才是根据结果决定下一步（对照动画里撞墙的左机与换路的右机）。

**分层挑战题（选做）**
- **8～11 岁：**做主线三题；可加口头一问「文件没写进去，可以宣布完成吗？」
- **12～14 岁：**「如果返回的结果不送回来，下一轮会缺少什么信息？」（要点：成功、失败和文件内容都可能影响下一步）
- **15～18 岁：**「如果三步永远按固定顺序播放、不根据返回结果改变行为，这段演示是否已经证明了 Agent 的自主决策？」（要点：区分预设流程与 Agent 根据结果选择行动）

## 5. 分镜自检（成片前过一遍）

> 本清单已于 2026-09-20 提升为课程级真源（《[课程设计规范](../50-课程/课程设计规范.md)》§六，含同日新增五条：30 秒钩子/一镜一事/比喻回收/术语/带走一句话）；本课成片前按规范清单过，下列六条为原始出处。

- **悬念链自检（v7）**：每段最后一镜留钩子、下段第一镜第一句接住；抽任意段尾 5 秒，观众心里应挂着问题。
- **表面一遍**：合上设计意图，只看画面与旁白，能复述一次完整运行吗？知识点应当像从演示里长出来，而不是旁白硬念。
- **每个镜头三推进**：同时做到——讲清一个小问题、露出概念的一个新侧面、推动「我也能搭」的感觉。只回答问题的镜头要改。诊断问句：「把所有教学信息抽掉，学生还愿意看这个画面吗？」
- **镜头节奏自检（v6）**：抽查任意 30 秒窗口，画面至少变化 3 次，否则该窗口的镜头要拆。台词字数按 §3.1 口径复核——每镜旁白全字符数（含标点、空格不计）≤ 秒数×4.0，超了就删字，不加快语速。
- **去组件化自检（v6）**：逐镜扫台词与画面——只要出现任何部件名或名牌，即判不合格；机器运转一律以「机器内部」呈现。
- **删除测试与体验优先**：去掉某个镜头若只损失一点趣味、不损失理解，就删；5 分钟容量宁密勿稀。时长与镜头数全绿不等于成立，先问「学生想看完吗、看完能复述吗」。
