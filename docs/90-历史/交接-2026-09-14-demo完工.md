## 3. 怎么跑

```bash
G=tools/godot/Godot_v4.7.2-stable_win64_console.exe

# 窗口模式验收（demo 演示 / 沙盒 / 各关）
"$G" --path game scenes/levels/l1/l1.tscn --resolution 1920x1080 -- --demo
"$G" --path game scenes/sandbox/sandbox.tscn --resolution 1920x1080
"$G" --path game scenes/levels/l2/l2.tscn   # l3/l4/l5 同理

# 测试（全套 18 套件 236 条；单套示例）
"$G" --headless --path game -s res://tests/levels/l1/run_l1_tests.gd
bash tools/check.sh

# 校验器（WSL python3）
wsl -e bash -lc 'cd /mnt/d/ai-project-lab && python3 tools/validate_assets.py && python3 tools/validate_concepts.py && python3 tools/validate_episodes.py'

# 生产管线（capture→图层→tts→合成→校验，约 14s）
bash tools/production/run_all.sh

# MCP 端到端冒烟（WSL 内）
wsl -e bash -lc 'bash sidecar/smoke_e2e.sh'

# 基准复跑（渲染项慢，可 --skip-render）
bash tools/bench/run_bench.sh --skip-render
```

操作约定：鼠标=视角、右键拖=平移、滚轮=缩放、`Tab`=预设机位、`空格`=跑/停、`，`/`.`=单步、**长按**搬（虚影=落点预测）、**点按**开（全屏）。
