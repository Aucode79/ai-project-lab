## 4. 这轮踩过的坑（新会话别再踩）

**Godot 侧**

- **headless 不出图、也不执行 shader**：`--headless` 下 `--shot` 会**挂死**（`frame_post_draw` 永不触发）。
  渲染取证只能开窗口跑；着色器的对错也只能这么验。
- **fragment 阶段的 `VERTEX` / `NORMAL` 是"视空间"**（官方文档原文），`MODEL_MATRIX` 是"模型→世界"。
  所以 `MODEL_MATRIX * VERTEX` 得到的既不是世界也不是视空间，而是**跟着相机转**的坐标。
  这种错误**编译得过、单张截图看着还挺像**，只在环绕镜头时才露馅。
- **`AnimatableBody3D`（带 `sync_to_physics`）的子节点，父节点不能"先进树再摆位"** —— 它进树那一刻把自己的
  世界变换当绝对值交给物理服务器，父节点之后再移动，服务器就把局部变换补偿回去，子节点留在原地。
  实测传送带带面被写到 `(2.5, −22.5, −1.75)`、落到世界原点。**载体一律"先摆位、再 add_child"**。
  另外这不只是摆位问题：**玩家拖动传送带时带面同样会脱开**。
- **量包围盒别用 `get_global_transform()`**：上面那类子节点在 headless 下可能**没接上父链**，
  包围盒会凭空宽 2 m、误报一堆"穿模"。要逐级合成局部变换。
- **`PlaneMesh` 默认 `orientation = FACE_Y`，也就是"水平"的一片** —— 两张幕布（播放器、求助屏）因此
  一直是**躺着**的，还从边框里穿出来。换 `BoxMesh` 时注意：`PlaneMesh.size` 是 `Vector2`，
  `BoxMesh.size` 是 `Vector3`（我漏改过一次，直接把三个套件打红了）。
- **L2–L5 是自动环绕相机**：不给 `--yaw/--pitch/--dist` 覆写，截图机位取决于"跑到第几帧"、不可复现；
  给了才会钉住。这也解释了 AGENTS 旧坑位里"预览图不可复现"的来源。

**流程侧（我自己的教训）**

- 多行源码替换要盯缩进：我有一次少打一层 tab，把 `for` 循环体挪到了循环外。
- "源码契约"类测试**必须先剥注释**：第一版草的向上判定被注释里的词喂饱，**假绿**过一次。
- 新写的回归锁都要**做反证**（把代码改回错误写法，确认它真的会红），否则不知道锁有没有用。
