## 项目是什么

一个装在自己电脑上的 AI 教育产品，教青少年搞懂 AI Agent 是怎么回事。表面是工厂与自动化的玩法，底下是真实的 Agent、工具调用与验证；学员不是听讲，是配置它、改坏它、修好它。

交付标准不是「学得开心」，是**能通过 CCF LMCC-T 认证**（青少年组大模型能力认证，两轮：第一轮客观题、第二轮编程题）。

## 给谁用

- **学员**：8–18 岁，用自己电脑，Windows
- **付费者**：家长
- **授课者**：你（配置云模型的 Key、发算力额度）

## 现在能跑什么

处于形态重做的第一步：**视觉验证**。目前只有一个 Godot 场景，用来回答一个问题——Godot 4 能不能做出「体素地块 + 引擎级光影」的画面。

这个场景还不是游戏，没有玩法、没有 Agent、没有知识网。它存在的唯一目的是让画面这件事先有结论。

## 怎么跑

前置：Windows 版 Godot 4.7.2 标准版，解压到 `tools/godot/`（181MB，不入库）。WSL 下可直接调用该 exe。

```bash
# 无头自检，验证场景能否完整搭起来（不弹窗）
tools/check.sh

# 截图，产出 game/shots/spike.png（会短暂弹窗）
tools/shot.sh
```

两条命令的成功标志：自检打印 `SMOKE RESULT: PASS`；截图打印 `OK .../spike.png`。
