# 2026-09-14 · 研究资料落库与 outline 索引

> 决策记录。落库目录 / outline_index.json 的 schema 与编号规则 / 生成与校验命令 / 已知限制。

## 背景

63 集微课大纲与全部竞品调研一直放在 WSL 的 `/root/lmcc-research/`，不在仓库里（`docs/00-入口/计划.md` §10、开放问题 5）。它们引用本文档集的产物路径（`episodes/`、`concepts.yaml`），实施前必须搬进仓库并定目录。同时，spec §5.1 要求一份**可 diff、可迁移的 conceptId 权威清单** `outline_index.json`——方块示例 id 只允许引用这份清单里真实存在的条目（`docs/00-入口/计划.md` §8 的复审教训）。

## 决定

### 1. 落库目录：`research/lmcc/`

- 源：`/root/lmcc-research/`（约 5.8 MB）→ 仓库 `research/lmcc/`，**排除 `tmp/`**，其余原样保留（含 `raw/` A–H 八份调研、两份 pdf、`outline.txt`、`tex.txt`、四份中文 md）。
- 复制方式：`wsl tar`（管道 `tar cf - --exclude=./tmp . | tar xf -`），中文文件名经 tar 原样保留，无转码。
- 核对结果：**19 个文件、5,527,528 字节**，与源目录（排除 tmp 后）逐一相符；`教学大纲-青少年组.md` 877 行。
- `outline_index.json` 生成后落在同一目录 `research/lmcc/outline_index.json`，与数据源同处。

### 2. `outline_index.json` 的 schema

顶层字段：

| 键 | 含义 |
|---|---|
| `version` / `source` / `generator` | 版本号、数据源文件、生成脚本（可复现） |
| `conceptIdRule` | 编号规则一句话说明 |
| `counts` | `{episodes, concepts, episodeConceptLinks}` 派生计数（spec §5.3「派生值 == 实际组装值」的锚） |
| `episodes` | **63 集**，每集 `{id: "e{NN}", title, unit, marker, syllabusRef}`（id/title/unit 逐字取自 §3 标题；marker 取自「标记」行；syllabusRef 为「考纲」单元原文） |
| `concepts` | **77 条目**，每条 `{conceptId, label, chapter, chapterLabel, item, globalNo, marker, difficulty, examTypes, episode, episodes}` |
| `derivedEpisodeLinks` | 材料题二跳推导出的集-条目链接及出处（见下） |
| `parseNotes` | 解析器没有强行匹配的原文（如 T3 知识点、模考集「全」），带 reason |

条目字段说明：

- **`conceptId` = `c{章号}.{章内序号}`**（spec §5.1）。章号 = 附录 A「章节-条目」的中文章号（一~十二）；**章内序号 = 附录 A 行在该章内的出现顺序**（附录照抄官方大纲原文顺序，不自造）。与 §2 总表「覆盖大纲条目」列的区间（一 1–4、四 17–30…）逐章对账。
- `label`：附录 A「章节-条目」单元**全称，不截断**（如 `三-Transformer 模型的基本结构组成`）；`item` 是去掉章号前缀的条目名。
- `marker`：三级标记 必修/加考/拓展（照抄附录 A 标记列）；`difficulty` 1–3；`examTypes` 照抄考核方式列。
- `episode`：**主编排集**（episodes 中集号最小者）；`episodes`：该条目出现的**全部集**——3 个条目挂双集（一-验证及评测 E05/E06、三-注意力机制 E11/E12、四-自监督学习 E17/E19），单值字段会丢信息，故双字段并存。
- `episodes` 的取值是三源并集：附录 A「集号」列 ∪ §3 各集「考纲」行引用 ∪ 材料题推导。

**材料题二跳推导**（唯一一条解释性规则）：专项集 E60 的「考纲」写「例卷材料题 1、2」，本身无章条目；demo L5 关（视频 E60）又要求它有条目。推导路径全部在大纲原文内：E60 考纲 → §1.2 材料题表「对应知识点」列 → T1 = 十-智能体工具使用（c10.3）、T2 = 八-提示学习-检索增强（c8.5）。每次推导都记入 `derivedEpisodeLinks`，可追溯、可剔除。

锚点样例（验证编号未自造）：`c3.1` = 三-注意力机制、`c4.5` = 四-优化设置：基于批次数据的训练方法。

### 3. 生成与校验命令（WSL，仓库根 `/mnt/d/ai-project-lab`）

```bash
python3 tools/build_outline_index.py    # 解析大纲 → research/lmcc/outline_index.json
python3 tools/validate_outline.py       # 校验，退出码 0 = 通过
```

生成脚本内置自检（不满足即失败退出）：63 集连续、附录 77 行、每章条目数对 §2 总表、附录全局序号章内连续、§3 考纲引用全部能在附录 A 找到同名条目、两个锚点 conceptId、五关集非空。输出幂等：无时间戳、键序确定，重复运行字节级一致（md5 复验过）。

校验脚本检查：conceptId 格式且**无重复**、episodes 恰为 e01–e63 **无缺号**、五关视频集 e49/e51/e50/e40/e60 存在且各自条目 ≥1、全部 label 非空、episode == episodes[0]、链接不指向不存在的集。当前输出：77 条目 / 63 集 / 83 链接，五关 e49=1、e51=1、e50=1、e40=1、e60=2，标记分布 必修 27 / 拓展 43 / 加考 7（与附录 A 统计行一致）。

## 已知限制与取舍

1. **表格与嵌套解析的取舍**：解析器只认四张结构固定的表/行（附录 A 表、§2 总表区间列、§1.2 材料题表、§3 每集的「时长｜标记｜考纲」行），不尝试理解大纲里的任意表格或嵌套语义。材料题知识点采用「精确匹配附录条目，或去掉章节名中缀后精确匹配条目名」两条规则，**不做前缀/模糊匹配**——因此 E61（论文阅读拆解，视频对应 L5 讲评之外）的 T3 知识点「九-长思维链」「十一-评测」「七-解码加速（早退）」无法唯一对应到条目（如「九-长思维链」vs 条目「九-长思维链模型」），记入 `parseNotes` 而不是猜一个；E61 在索引中没有条目链接。E62/E63 的考纲「全」（模考覆盖全集）同理不展开。
2. **三源并集的含义**：`episodes` 是「该条目在这个集被引用/编排」的并集口径。附录 A 与 §3 唯一的差异是 E12 以扩展知识点身份带出 c3.4（Transformer 基本结构组成，附录只标 E14），并集口径把它计入，消费方如需「主编排集」用 `episode` 字段。
3. 官方大纲若重排条目顺序，按 spec §5.1 应更新本文件并附迁移映射，序号不默认稳定。
