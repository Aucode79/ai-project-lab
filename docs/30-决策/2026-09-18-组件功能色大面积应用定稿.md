# 组件功能色大面积应用 · 定稿

> 2026-09-18。记录组件重设计的配色方向裁定：从「灰壳 + 小面积点缀」改为「大面积功能色覆盖外壳与顶面」。配套评审样例 [`10-契约/specs/2026-09-18-unfolding-study.html`](../10-契约/specs/2026-09-18-unfolding-study.html)。

## 背景

《2026-09-18 组件设计》原案沿用 `asset_style.gd` 的六角色色板：大面积 SHELL 浅灰机壳，ACTION/SIGNAL/CORE 只出现在工作槽或状态格。用户评审后认为该方向过于抽象，明确要求「大胆使用色彩来表示功能」。样例页给出 A（明亮功能色）与 B（深色仪器）两案，并附去色检查与状态示意，用户于同日选定 A。

## 备选

- **A · 明亮功能色**：七个功能族各占一色，饱和度较高，浅底与去色后均可读，适合青少年教学场景。
- **B · 深色仪器**：同一映射降低明度。整体偏暗，去色后组件间层次损失更大，落选。
- **维持原案**：灰壳 + 点缀色。用户已否决（太抽象、折叠态看不出功能）。

## 选择

采用 A。功能族与颜色的映射：

| 功能族 | 色值 | 说明 |
|---|---|---|
| 输入 / 消息 | `#24b9cf` 青 | 对应旧 SIGNAL 语义 |
| 记忆 / 变量 | `#4279d4` 蓝 | 新增族 |
| 模型请求 | `#f2c43d` 黄 | 对应旧 CORE 语义 |
| 工具 / 执行 | `#ef743b` 橙 | 对应旧 ACTION 语义 |
| 循环 / 调度 | `#9261c5` 紫 | 新增族 |
| 交付 | `#68ab5d` 绿 | 功能身份，不表示运行成功；成功另用状态标记 |
| 校验 / 限额 | `#546066` 石墨 | 新增族 |

配套规则：颜色覆盖外壳与顶面，形状继续区分组件；状态（空闲/工作/成功/失败）用方印、叉纹与文字表达，不替换功能色；去色后仍可辨认（样例内置去色检查）。INK/STRUCTURE/PAPER 等中性色继续承担凹槽、骨架与读面。

## 后果

- `asset_style.gd` 现有常量不足以覆盖七个功能族；实施批次需以新色板回写该文件，一次过，避免两套色值并存。
- 《2026-09-18 组件设计》§2.1 色彩表与新映射冲突，以本 ADR 与样例为准，表值随实施批次修订。
- 旧 28 件资产不受影响，继续运行到各批次替换；`concepts.yaml` 不动。
- 去色检查进入每批样件的验收动作。

实施更新：已回写共享色板与生产组件目录。青色按已验收样件统一为 #24b9cf。旧关卡本轮也共享表面色与倒角，但保留独立教学语义。
