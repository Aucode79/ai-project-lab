# 2026-09-16 · 沙盒改箱庭浮空岛，并让世界配方可替换

## 背景

用户看完《Zoy》（任天堂风箱庭探索游戏，类似《蘑菇队长》）的前瞻片后要求：
**"重新设计我们的沙盒……先看这个视频，想办法实现它的效果"**。

当时的沙盒观感问题：奶油色无边界平地甲板上摊开 28 件组件 + 28 张铭牌 + 4 张分组立牌，
读作"零件目录摊在米色桌上"。**它不成立的地方不是技术，是"这不是一个地方"**——
没有天空、没有边界、没有景深、没有明暗对比。

同时有一条工程约束：沙盒与五关共用 `scripts/scene/world_builder.gd`（调色板 / 地形 /
环境 / 光照的唯一真源），直接改它会连带改掉五关与 bench 的观感——那不是本次要动的范围。

## 备选

1. **只改沙盒的参数**（调色板/光照照旧由 world_builder 出，沙盒覆写几个值）——
   代价最小，但"浮空岛"是形状改动，`terrain_generator.gd` 是无边界平地生成器，
   参数改不出来。而且沙盒与关卡会继续互相牵制。
2. **改 world_builder 全局换风格**——一套配方同时服务"能承载工位的无边界甲板"与
   "有限的小块陆地"，两个诉求相反，必然有一边将就；且五关视觉回归没有自动断言
   （只有 6 个套件 preload `.tscn`），风险不可控。
3. **给世界装配加"配方可替换点"，沙盒另起一份配方**——组装顺序仍只有一处，
   沙盒与关卡各留各的配方，互不影响。

## 选择

**取 3。** 具体：

- `level_scene_base.gd` 的世界装配拆出四个可覆写点：
  `_add_environment` / `_add_sun` / `_add_particles` / `_add_terrain_recipe`。
  默认仍调 `world_builder`（五关与 bench 零改动），沙盒覆写这四点换成
  `scripts/sandbox/sandbox_diorama.gd`。
- 新增三个沙盒专属文件：`sandbox_island.gd`（浮空岛地形 + 调色板唯一真源）、
  `sandbox_diorama.gd`（天空 / 光照 / 移轴 / 树石 / 相机机位）、
  `sandbox_grass.gdshader`（草叶）。
  > 2026-09-16 后续修正：**草叶 shader 与草场 MultiMesh 已删除**，草改成顶层方块的
  > 表面（用户口径：不要把草做成长那么高的东西）。见 `美术方向.md` §5 与
  > `20-验收/2026-09-16-沙盒草改为顶层方块草皮.md`。
  > 2026-09-17 后续修正：**自然装饰全删**（树石 / 浮尘粒子），`sandbox_flora.gd` 已移除，
  > `sandbox_diorama.gd` 的 `add_particles` 留空覆写；见
  > `30-决策/2026-09-16-教学资产表面细节尺度.md`。
- 岛顶面高度仍是 `WorldBuilder.DECK_TOP_Y = 23`，**工位摆位 / 物理 / 交互一行未改**，
  换的只有观感。
- 顺带修一个真 bug：轨道相机的**进场机位原来走补间**，而补间实测跑不完 —
  相机会停在 `OrbitCamera` 的默认姿态（14 m / pitch 0.55）而不是请求的预设。
  新增 `OrbitCamera.snap_preset()`：进场直接就位（开局从默认姿态动画过去本来也没意义）。
- 新增回归套件 `tests/sandbox/run_island_tests.gd`（8 条）：形状不变量（顶面平整、
  `is_land()` 与体素逐点一致、岛体有限且收束、四段地层都在）、灯笼柱、材质库对账，
  以及**场景装配**（含上面那个进场机位回归锁）。

## 后果

- 沙盒与关卡的美术方向各自独立演进；改沙盒不会再动到 L1–L5 与 bench。
- 代价：多一份配方要与 `world_builder` 保持"同一套静态方法名"的约定
  （两者都是被 `level_scene_base` 按方法名调用的配方脚本），改名要同时改两处。
- 地形从"无边界平地"变成"有限小岛"后，`VoxelTerrain.max_view_distance` 与
  `VoxelViewer.view_distance` 从 256 / 96 收到 48，生成的块数从上千降到百余块；
  生成器对岛外块用 `buffer.fill(0)` 提前返回（**不能用 `clear()`**——它会把缓冲区
  尺寸复位成 (0,0,0)，地形会整块丢弃）。
- 测试基线 18 套 288 条 → **19 套 296 条**（`bash tools/run_tests.sh` 23 项）。
- 美术口径见 `docs/10-契约/美术方向.md`「沙盒另起一配方：箱庭浮空岛」节；
  沙盒观感已按 `tools/measure_image.py` 对齐参考片（亮度 143/145、饱和度 67/63）。
