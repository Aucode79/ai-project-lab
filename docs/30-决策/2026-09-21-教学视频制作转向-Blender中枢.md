# 2026-09-21 · 教学视频制作转向-Blender中枢

> 重大决策记录。教学微课的**生产管线**整体换轨：旧 `tools/production/`（Godot Movie Maker 抓图 → HTML/CSS 场景 → edge-tts → ffmpeg 脚本）退役，改用 **Blender 制作中枢**。工具链真源见 [`../../tools/video/README.md`](../../tools/video/README.md)；新会话交班见 [`../00-入口/交接-2026-09-21-Blender视频工具链.md`](../00-入口/交接-2026-09-21-Blender视频工具链.md)。本文只记裁决与理由。

## 背景

课程线已定（[课程总纲](../50-课程/课程总纲.md)、[课程设计规范](../50-课程/课程设计规范.md)、第一课 v7），[微课样片 w01](../20-验收/2026-09-19-微课样片-w01.md) 用旧 `tools/production/` 管线跑通过"HTML 动效为主 + 工坊 3D 插图"的出片链。用户 2026-09-21 复盘该管线后**整体否决**：

- **画面语言受限**：HTML/CSS 只能做平面动效与静态 3D 插图拼贴，做不出真正的镜头运动、景深、体积光与材质质感；教学里"拍出来"的三维场景感始终缺一块。
- **工程脆弱**：抓图 → 图层 → 配音 → 合成 → 校验五段脚本 + 两个运行域（Windows Godot 弹窗抓图 / WSL python 加工），任何一段漂移都要追三段数据文件（`data/*.json`、`layers/*/voiceover.txt`、分镜稿），维护成本高。
- **硬约束**：**零预算、无真人配音**。不外采商业剪辑软件、不请配音演员，一切必须落在可自持的开源/免费工具上。

用户明确要求重选制作中枢，在四个备选里定夺。

## 备选

| 方案 | 说明 | 否决/入选理由 |
|---|---|---|
| **Godot 引擎内拍片** | 直接在游戏引擎里搭景、动镜头、录屏出片 | 否决：引擎不是剪辑软件，时间线、字幕、混音、转场都要自己造轮子；渲染管线也不为成片画质设计 |
| **Blender 制作中枢** | Blender 作 3D 场景与渲染中枢，Godot 只做资产桥（导出 .glb 组件几何） | **入选**：免费开源、工业级 3D/渲染/时间线/合成、headless 可脚本化、有 Python API 能驱动逐字点亮字幕 |
| **DaVinci Resolve 免费版** | 免费剪辑 + 调色 | 否决：免费版功能受限；强 GUI 依赖、脚本自动化（Fusion/Python）门槛高，做不出程序化"说到哪亮到哪"的字幕驱动 |
| **Remotion** | React 代码化视频 | 否决：本质仍是 HTML/CSS 平面合成，与刚被否决的旧链同类，缺 3D 镜头与材质能力 |

## 选择

**Blender 制作中枢**。四单元已部署并冒烟验证完毕（2026-09-21）：

1. **Blender 5.2.2 LTS**（`tools/blender/blender-5.2.2-windows-x64/blender.exe`，build 2026-09-15，官方 sha256 校验一致）——中枢渲染/时间线/合成。headless EEVEE 冒烟与 glTF 导入冒烟通过。
2. **Godot → glTF 资产桥**（`game/scripts/video_pipeline/export_components_gltf.gd`）——把 26 件工坊组件按同源几何导出 `.glb`，供 Blender 摆位。
3. **faster-whisper 词级对齐**（`tools/video/.venv-win`）——拿配音的逐词 start/end，喂逐字点亮字幕。
4. **CosyVoice3 配音**（WSL `/root/opt/CosyVoice`）——本地零费用的中文 TTS，替代旧链的 edge-tts。

选它的关键：**一个免费工具同时提供 3D 场景、工业渲染、时间线剪辑与 Python 脚本面**，四单元都能 headless/脚本化，全栈零费用，符合"零预算 + 无真人配音"的硬约束。

## 后果

**旧管线退役**
- `tools/production/` 全链退役（2026-09-21 起不再维护、不再作为出片口径），仅保留历史产物与说明。历史产物 **保留不删**：`compose/`（成片）、`layers/`（图层/配音）、`shots/production/`（抓图）、`production/` 自身脚本与文档。
- 收官样片证据（[微课样片 w01](../20-验收/2026-09-19-微课样片-w01.md)）继续作为"实测语速、秒位差额、版式基线"的存档，不再扩产。

**资产与材质**
- glb 桥**只保几何与配色近似**，不保 Godot 内的表面细节/材质表现。26 件组件的**材质需在 Blender 侧重做**（砖缝/花纹/色板/倒角在 Blender 材质与着色器里重建，达到成片画质）。Godot 侧仍是教学与游戏的真源，两边材质各自维护。

**待开发**
- **逐字点亮字幕需 Blender Python 驱动脚本**：用 faster-whisper 给的词级 start/end，在 Blender 里程序化生成/驱动字幕（说到哪个字亮哪个字），旧链的 HTML `seek(t)` 逐帧截图方案不再适用。此脚本**尚待开发**。
- 分镜 JSON → Blender 时间线骨架的驱动脚本、26 件 Blender 材质重做、模板 `.blend` 同属待办，详见交接文档。

**约束与口径**
- **全栈零费用**：Blender、faster-whisper、CosyVoice3、ffmpeg 均为免费/开源，无版权采购。
- 成片规格仍以 [课程设计规范](../50-课程/课程设计规范.md) 为唯一真源（3–5 分钟、≤4 字/秒、禁整页截屏、版式三件套、逐字字幕跟配音）；旧链的 `zh-CN-XiaoyiNeural` 电平口径（mean −19.8 / max −1.6 dBFS）作为混音目标沿用。
- 新链的路径/版本/命令行/坑位**单一真源** = `tools/video/README.md`，本文不重复维护。
