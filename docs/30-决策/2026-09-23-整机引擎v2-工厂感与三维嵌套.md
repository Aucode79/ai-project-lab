# 2026-09-23 · 整机引擎 v2：工厂感与三维嵌套（Agent Lab 第三波）

## 背景

三维整机在 2026-09-22 两轮（可执行首版、分形铸造语言）之后功能已齐：确定性布局、三维端口拖线、结构化参数编辑。但观感停在"功能正确"：节点除色帽外全是扁盒，读不出 call/工具/进料/出料的类别；连线是一根同高直角带，读不出类型与流向；运行反馈只有一次性脉动线；模块内部仍要跳二维图看。本轮按 Fractal Foundry 与工厂运营游戏的口径做引擎 v2：形状读出功能、走线读出类型与方向、运行读出生命、三维能钻进模块。代码分三波落地——形状与走线、动画核心两波已落地，`agent_lab.gd` 集成第三波进行中，决策随第三波收口。

## 备选

1. 只调色不改形——统一视觉角色色板已经七角色封顶，再加对比救不了"所有节点同一副扁盒剪影"；工厂游戏的机器可读性来自形状词汇（Factorio 每种机器有独有轮廓），不是颜色数量。且色板零新增是 2026-09-17 统一视觉角色契约的现行约束。
2. 引入通用图布局库/力导向或寻路——v2 的避让只是"穿脚印外移一档 + 车道被占继续外移"两条确定性小规则；通用库引入依赖，且表达不了"控制流定列、数据上带、同类逐线车道"的教学语义。同程序同画面（视频 glTF 导出与 headless 测试的前提）也要求确定性规则而非物理模拟。
3. 维持二维为主、三维仅展示——"模块里还有模块"就永远停留在叠板隐喻，2026-09-22 ADR 已知债「三维视图不显示模块内部」被永久化；已落地的三维端口拖线也会退化成半成品。二维编辑器保留为精编入口，但三维必须能读程序。

## 选择

**形状语言 v2**（`game/scripts/lessons/machine_view.gd`；全部纯盒、色板零新增、extents 不变、摆位仍落 0.25 m 网格）：

- **call/trycall**：三层叠板向右上收窄，前缘嵌深色内衬薄板（`Style.INK`）——"板下还有板"；trycall 另加底板四周一圈异色边框板（`Style.ERROR`），侧向中段留端口槽与 call 区分。
- **tool**：按绑定名分形——`world.*` 顶加小天线（细柱 + 顶块，读作"感知世界状态"）；`fs.*` 前缘纸盘低板（`Style.PAPER`，读作"吃进文件"）。
- **input / return**：input 前缘两级台阶递降的进料坡板；return 前缘矮出料唇板——机器有了进料口与出料口。

**走线 v2**（同文件）：

- **双层 + 车道**：控制线基高 `WIRE_Y = 1.0`、数据线 `DATA_WIRE_Y = 1.25`，同类型逐线错 `WIRE_LANE = 0.25`；分配按 from/to 字典序（`_edge_sort_key`）确定性排序。通道使用深色高对比材质，与浅色平台区分。
- **直角路线**：每条通道分为起升、X 向、Z 向、落到端口四段，避免 X/Z 对角位移被画成宽板。
- **方向标**：轴向水平段每 1.0 m 整米格点一枚 chevron（两片薄板收窄成箭头）；末端箭头沿最后一段水平通道指向目标端口。
- **避让**：水平段穿中间节点脚印（extents 近似 AABB 外扩半线厚）单档外移；目标车道与先前分配在 x 区间重叠则继续外移。`wire_path(a, b, lane = WIRE_Y)` 保留四点兼容形式；整机与拖线预览改用 `channel_path` 生成直角路线。

**动画核心**（`game/scripts/lessons/machine_anim.gd`，241 行纯静态函数，`_process` 数学驱动不用 Tween，headless 可测）：

- **数据包**：沿折线弧长插值行进，里程整格化 0.25 m（`packet_quantum`，FFF-276 精神——表现层的量整格化）；速度 `PACKET_SPEED = 3.0`。
- **运行游标**：会走的标准方块——0.5 m 身体 + 双足 + 前端工具头（`EXEC_COLOR`）+ 头顶身份标记（`Style.CORE`），已定稿设计的落地；行进带 0.05 m 浮动、朝向行进方向。
- **工作态**：`set_working` 遍历节点全部网格在哑光与自发光间切换，emission 取基色、能量压低档——样式契约在 `asset_style.gd` 新增 `Style.lit`（emission = 基色、0.35 档），machine_anim 运行点灯按同一约定在内部按色缓存（0.55 档）。
- **递归深度**：enter/leave 按 callId 配对推导深度，`depth_plates` 点亮 call 叠板前 N 层并写 `DepthBadge`。
- **限速回放**：事件队列每 `EVENT_INTERVAL = 0.15` s 出队一条，与数据包推进同帧驱动。

**本轮交付**（第三波集成）：`agent_lab.gd` 集成动画反馈（替换一次性脉动线）；点击 call 节点三维钻入模块内部 + 面包屑（重复模块标「第 N 层」）；二维编辑器保留为精编入口——关闭 2026-09-22 ADR 已知债「三维视图不显示模块内部」。

## 后果

- `machine_view.gd` 单一真源进一步收敛：形状、走线、动画路径同出一处——machine_anim 的包路径直接消费 `build()` 产出的 wires 折线（对任意折线段数通用、不假设 `wire_path` 点数），动画不再自带几何；既有场景 / headless 测试 / 视频 glTF 导出三处消费方不受影响。
- 发光只属于运行态：静态摆件一律哑光，"正在工作"才点灯——延续「发光越少越精确」的旧教训，机器的"活"靠动画读出而不是常亮。
- `PORTS` 双镜像债仍在：`module_compiler.py` 与 `machine_view.PORTS` 依旧两份同形（与 2026-09-22 同构，靠编译器校验兜底），本轮未收敛。
- 无限分形缩放明确不做：三维钻入按"每次进一层完整模块图"展开（面包屑记深度），不做 Fractal Foundry 式无限自相似缩放——教学程序层数有限，缩放相机与 LOD 的复杂度不值。
- 新增回归套件：`tests/agent_lab/run_machine_anim_tests.gd` 与 `tests/agent_lab/run_machine_nav_tests.gd`，锁弧长插值 / 整格里程 / 深度推导与车道分配 / 避让 / 兼容口径。
