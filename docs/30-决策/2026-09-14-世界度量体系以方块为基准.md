# 2026-09-14 · 世界度量体系以方块为基准

## 口径裁决与理由

**基准**：1 标准方块 U = `STANDARD_CUBE_SIZE` = 0.5 m（`asset_node.gd` 常量为唯一来源）；1 世界格 = 1 体素 = 1 m = 2U——地面体素天然是方块的两倍，整数倍合规。

**分层规则**（详表见方块体系.md）：

- **a · 主轮廓尺寸**（资产 bounding、场景大件外框、物理碰撞体、生成台基座）必须 n×0.5；
- **b · 摆位 / 部件中心**必须 n×0.25（半块网格，整格优先）；
- **c · 豁免不计量**：端口位置与端口标记、薄板/细杆/线缆/护栏等工艺件（厚度 <0.25 保持；进主轮廓或高度链加法时升 0.25/0.5 凑格，豁免件的中心随厚度一并豁免）、Label3D/粒子/头灯、圆形轮、相机与交互参数、bench。

**为什么分层，而不是"一切 n×0.5"**：严格一刀切在三处无解——

1. **薄板**：厚 0.06~0.16，就近吸附到 0.25 的倍数会吸到 0，板直接灭失；
2. **端口**：位置 = 表面 + 伸出量，强制落格则端口悬空或嵌入壳体；
3. **高度链**：厚度参与叠放加法，逼工艺件守格就是逼薄板灭失，不逼则链尾全歪。

分层既守住"孩子看得见的占格量全部以方块为单位"，又不逼死工艺细节。0.25 合法是因为它是半块（0.5 块），仍是方块度量，不引入第三种单位。

**第一轮"非 token 部件整体豁免"的口径自本轮废除**：机械本体、台面等的主轮廓照 a 层受约束，只有 c 层清单豁免。

## 豁免与待裁决清单

**豁免（c 层，不计量）**：端口位置与端口标记；薄板/细杆/线缆/护栏等工艺件（厚度 <0.25 保持，进主轮廓或高度链加法时升格；中心随厚度派生一并豁免）；Label3D/粒子/头灯；圆形轮；相机与交互参数；bench 基准场景（`game/bench/`，`docs/20-验收/测量结果.md` 依赖原尺寸复现，永不动）。

**待裁决（开放问题，裁后回写方块体系.md）**：

1. 端口是否对齐半块格（当前豁免）；
2. 工艺件是否全面"块状化"——薄板升 0.5 厚的 Minecraft 美学，进高度链的件已这么做，未全面铺开；
3. 圆形轮是否方轮化；
4. 体素分辨率是否从 1 m 提到 0.5 m——1 体素 = 1 方块的严格 Minecraft 模型，数据量与坐标重构成本大，当前以"1 体素 = 2U"声明替代。

## 块状化 v2（同日二次裁决）

> 2026-09-14 同日晚些时候的二次裁决。上节分层口径（v1）里"工艺件/端口/圆轮豁免"的表述自本节起废除。v2 后的分层口径正文已回写 [`../10-契约/方块体系.md`](../10-契约/方块体系.md)「世界度量体系 · 以方块为基准」节。

**触发**：用户渲染预览后反馈——"还有一些小组件不是按方格去呈现的"。画面里可见的贴面、薄板等工艺件仍按原厚度自由取值，孩子看得出"不按方格"。这句话等于对待裁决清单第 2 项"工艺件是否全面块状化"投了赞成票，主会话随即定稿 v2 并派工实施。

**裁决（规则四条）**：

1. **可见件全部 n×0.25**：可见工艺件不再豁免——薄板、细杆、护栏等一律取 0.25 的倍数，最低厚 0.25（v1"厚 <0.25 保原值"口径废除）；
2. **中心落 n×0.25 格**：部件装配中心一律落半块网格；
3. **半嵌贴面**：0.25 厚贴面件的中心落在支撑面格线上，半嵌半露——化解"贴面件中心必偏移"的矛盾（浮贴则中心 = 表面 + 0.125，永远不在格点）；
4. **圆件方化**：圆形轮改方轮（待裁决第 3 项裁为"做"）。

**裁决（端口与豁免收缩）**：端口标记 `PORT_MARK_SIZE` 0.1 → 0.25、端口位置吸附半块格（待裁决第 1 项一并裁为"做"）；豁免层（c 层）收缩为仅三类——**不可见功能面**（碰撞检测面、透明拾取体）、**非几何参数**（Label/粒子/灯光/相机/交互）、**bench** 基准场景。待裁决清单第 1、2、3 项就此全部裁决，第 4 项（体素分辨率 1 m → 0.5 m）仍开放。

**删件两处**：

- `base_block` 底座裙边（1.0×0.06×1.0 工艺豁免件）删除——本体即全部，1 格见方的裙边反而误导占格读数；
- `base_label` 装饰边框（0.04 包边）删除——0.04 无法落进 0.25 格，保留即永久豁免件。

**影响面**：资产库 12 件（`game/scripts/asset_lib/`）、16 件关卡组件（`game/scripts/levels/l1..l5/`）、五关小车方轮链（小车轮现为 CylinderMesh 圆轮：`l1_scene.gd`、`l2_scene.gd`、`l4_scene.gd`）。

**落码时点注记**（2026-09-14 文档写作时核对代码）：`STANDARD_CUBE_SIZE := 0.5` 已在码（`asset_node.gd:24`）；`PORT_MARK_SIZE` 文档时点仍为 0.1（`asset_node.gd:39`），0.25 为本裁决施工目标；`base_block` 裙边与 `base_label` 包边文档时点仍在码，删除属本裁决施工项。施工以本节为验收口径；若最终落码与上述目标数字不符，以代码为准回写本文。
