| 单元 | 状态 | 入口 |
|---|---|---|

三条可复用命令（细节与坑位见真源 README）：

```bash
# ① 导出 26 件组件 .glb（Windows，headless，退出码 0）
./tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path game \
  -s res://scripts/video_pipeline/export_components_gltf.gd

# ② 配音（WSL，环境变量入参 CV3_TEXT/CV3_OUT/CV3_MODEL/CV3_PROMPT，输出 48kHz/mono/16bit）
wsl -e bash -lc "cd ~/opt/CosyVoice && .venv/bin/python smoke_cosyvoice3.py"

# ③ 词级对齐（Windows，GPU cuda/float16 0.56× 实时）
D:/ai-project-lab/tools/video/.venv-win/Scripts/python.exe D:/ai-project-lab/tools/video/scripts/align_smoke.py \
  --audio <wav> --out <json> [--language zh] [--device cuda]
```

产物落在 `game/shots/video3d/components/<id>.glb`（26 件，已被忽略，不入库）；冒烟取证在 `tools/video/smoke/`。

## 2. 还缺什么（你要建的）

按依赖顺序：

1. **模板 `.blend`**：固定的 Blender 工程骨架——世界/光照/渲染设置（EEVEE）、相机约定、输出规格（1080p25）、画面版式三件套（左上课号牌 / 右上进度条＋段名 / 底部字幕条）。一切新片从这个模板派生。
2. **26 件组件的 Blender 材质重做**：glb 只保几何与配色近似，**材质需在 Blender 侧重做**（砖缝/花纹/色板/倒角在材质与着色器里重建，达到成片画质）。Godot 侧材质保持不动，两边各自维护。
3. **分镜 JSON → Blender 时间线骨架的驱动脚本**：读分镜稿/`data/*.json`，在 Blender 里程序化搭出镜头序列（相机关键帧、段落切分、时长对齐秒位）。**尚未开发。**
4. **逐字点亮字幕驱动脚本**：用 faster-whisper 的**词级 start/end**，在 Blender 里生成并驱动字幕——**说到哪个字亮哪个字**，跟配音走、不靠估。旧链的 HTML `seek(t)` 逐帧截图方案不再适用。**尚未开发。**
5. **ffmpeg 响度链**：把成片混音拼到 **mean −19.8 / max −1.6 dBFS** 不削顶（沿用旧链实测口径，作为混音目标）。

## 3. 建议试点路径（第一课 v7 段 1 的前几镜）

先用**第一课 v7 段 1 的前几镜**打通最小闭环，再铺全片：

1. **搭景**：把该段涉及组件的 `.glb` 从 `game/shots/video3d/components/` 导入 Blender（用模板 `.blend`），按分镜稿摆位/布光。
2. **配音**：CosyVoice3 按该段台词合成（先确认 wetext 已预热，否则中文正则化静默失效）。
3. **对齐**：faster-whisper 对合成音做词级对齐，拿逐词 start/end。
4. **出片**：Blender 渲染 **1080p25 / H.264 / CRF 18**，接响度链到 mean −19.8 / max −1.6 dBFS，套版式三件套与逐字字幕。

先出前几镜、按 [`../50-课程/课程设计规范.md`](../50-课程/课程设计规范.md) 的自检清单核一遍构图/字幕/语速，再决定是否照此铺满整课。
