# 美术统一与组件工坊 · 2026-09-18

本轮把 26 件设计样件接成正式组件工坊，同时统一现有沙盒与五关的功能色、倒角和阅读面。它完成的是视觉与操作层；新组件不是旧 28 个教学资产的同义替换，也没有据此宣称真实智能体已接入。

## 怎么操作

```powershell
& tools/godot/Godot_v4.7.2-stable_win64_console.exe --path game --resolution 1920x1080
```

- 点组件或它的字砖，打开四层阅读；按钮可直接展开，Esc 返回世界。
- 长按搬运；中键旋转、右键平移、滚轮缩放；Esc 取消搬运。
- PgUp / PgDn 翻页；F 聚焦上次点开的组件，Home 恢复当前页构图。
- Ctrl+S / Ctrl+O 保存、读取工坊布局。它与旧沙盒的逻辑装置存档是不同内容。
- F1 切换场景，H 在工坊字砖上显示操作说明。

## 性能与实际分辨率

性能脚本：`game/tests/bright_loop/measure_workbench.gd`。窗口运行，静置、环绕、拖拽各 60 秒；关闭 VSync，保留项目抗锯齿设置；记录实际 framebuffer 尺寸、GPU、载入时间、P50/P95、draw calls、三角形和渲染内存。三个工况各自恢复工作镜头，拖拽对象保持在镜头内。

**口径纠正**：最早的 `before.png/json` 实际是 1280×720，尽管初始化脚本请求了 1920×1080。已依据 PNG 头回写原始 JSON；不得用这组数值宣称 1080p 性能改善。新工坊默认每页四件，旧版每页十二件，构图也不同，不作严格的同画面提升比例比较。

最终原始数据为 `final-1080.json`，运行日志为 `final-1080.log`。实际 framebuffer **1920×1080**，NVIDIA GeForce RTX 5060，Forward+，4× MSAA + FXAA，关闭 VSync、无 FPS 上限。场景构建与字砖烘焙共 594 ms（不含进程启动）。

| 工况（各 60 秒） | 帧数 | P50 帧耗时 | P95 帧耗时 | 末帧 draw calls / 三角形 |
|---|---:|---:|---:|---:|
| 静置 | 5262 | 11.278 ms | 15.262 ms | 62 / 3246 |
| 持续旋转 | 6461 | 8.561 ms | 15.067 ms | 120 / 6694 |
| 镜头内拖拽 | 8533 | 6.899 ms | 10.801 ms | 63 / 3554 |

三种工况的 P95 均低于 60 Hz 对应的 16.67 ms，实测达到本机交互目标。draw calls、三角形与约 294 MiB 渲染内存是结束时的采样，不是峰值；帧耗时是主循环墙钟间隔，不等于纯 GPU 时间。不同工况顺序、可见物与系统负载不同，不能据此说拖拽比静置更省时，也不承诺低配 GPU 表现。共享倒角与颜色材质、一次烘焙字砖、悬停降频共同减少重复开销；没有以削减实体组件数冒充同画面提速。

```powershell
& tools/godot/Godot_v4.7.2-stable_win64_console.exe --path game `
  -s res://tests/bright_loop/measure_workbench.gd --resolution 1920x1080 -- `
  --out=res://shots/art-upgrade/unified-20260918/final-1080 --seconds=60
```

## 保留的边界

- 工坊没有真实 smolagents 事件源，运行观察仍只显示静态可达；会话形象没有假装在执行任务。微课地屏的完整内容与播放状态也未接入，目录继续明确声明这两项缺口。
- 旧 28 个教学资产保留独立语义与教学流程。没有捏造它们与新 26 件的一一映射，未改 `concepts.yaml` 或编译器。
- 旧关卡仍保留原有面板文字与部分 Label3D；新工坊已取消浮空文字。旧关卡文字的全面字砖迁移，以及真实智能体驱动的会话动画，不能列为本轮已完成。
- 单包围盒搬运不支持把物件塞进另一组件的凹槽。全局保存的是工坊位置，不是课程逻辑装置。
- 未做首次使用者可用性测试，未测低配 GPU，也未制作五关完整微课或 63 集课程视频。

## 文件职责

新增 `component_catalog.gd` 是正式运行的组件几何目录；`block_surface.gd` 由资产基座、组件目录、教学场景三个真实消费者共享；`text_tile.gd` 专管字砖烘焙；`scene_menu.gd` 专管临时场景导航；`workbench_floor.gdshader` 只负责工作地面格线。无新增运行时依赖。测试与截图脚本分别负责回归和可复查证据，不作为产品运行入口。
