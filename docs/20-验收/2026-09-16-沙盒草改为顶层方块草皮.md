# 沙盒 · 草改成顶层方块的表面（2026-09-16）

> 用户口径：**"不要把草做成长那么高的东西。可以把方块的最上面一层渲染成草的样子，总体形状还是正方体。"**
> 证据在 `game/shots/art-upgrade/A3/`（派生产物，已 gitignore）。

## 0. 改了什么

**删掉整套草叶几何**：`sandbox_grass.gdshader`（整个文件）与 `sandbox_flora.add_grass()`
（约 1.9 万株 MultiMesh、两片交叉锥形叶 + 风摆动画）。同时删掉只服务于它的
`GRASS_*` 常量、`_blade_mesh()`、`_jitter()`，以及 `sandbox_island.is_turf()`（改名为
`is_turf_top(rr, x, z)` 并**接进 `_top_type_at`**，让"用色"与"草长在哪"共用同一处判定）。

**草改由方块自己的表面表达**（`sandbox_block.gdshader` 新增 `pattern_kind 3`）：

| 面 | 画什么 |
|---|---|
| 顶面（含顶棱倒角，`abs(nrm.y) > 0.5`） | 成片草色：两级平滑噪声定深浅（约 2 m 成片 + 约 0.3 m 细斑），再乘逐块微差 |
| 侧面 | 土壤色 + 顶部 0.20 m 的**草皮断面**（界线带锯齿）→ 崖口读作"草盖顶的土崖" |
| 几何 | **一点不加**：方块仍是正方体，岛形与剪影不变 |

`pattern_kind 3` 只挂在**顶层方块**上 —— `sandbox_island._top_type_at` 只在 `d == 0` 给
T_TURF / T_DRY，其下全是地层色。

## 1. 顺带解决的旧问题

上一轮量出来"铺装上有孤立草"的根因（草皮斑 + 1/4 抽样 + 不认生成台占位）随之消失：

- 不再有 19368 株高草，其中 686 株立在铺装砖上、110 株落在 5 台机器的占格里（最多
  `mach_verify_gate` 66 株）——**这些现在都不存在了**，因为草不再是几何。
- 草皮斑上不再有"孤零零一根"，而是整格渲染成草皮（斑即草皮顶块）。

## 2. 两条踩过的坑（都写进了 shader 注释与 `美术方向.md` §5）

1. **成片要用平滑噪声**。第一版拿 `floor()` 的硬格子做"成团"（`hash31(floor(wp.xz*1.7))`），
   出来是一块块高对比方斑，读作**烧焦的印记**；改成 `vnoise()`（双线性 + smoothstep，两级）。
2. **顶面不能给暖金/沙色**。第二版沿用了被删掉的草叶 shader 的暖金梢色 `#FFA529`，
   整圈读作**沙地**。草得有自己的绿 → 取低饱和暖橄榄绿 `#33431B → #6F8F45`。

## 4. 未决：与"避开《我的世界》配方"的张力

`美术方向.md` 开篇 §② 明说"**饱和绿草 + 蓝天 + 土黄**是 MC 的签名配色，要避开"，
而现在**顶面是绿草、天空是饱和蓝、铺装是暖砂**——三条同时在场。

我的判断：本项目的其余身份（浮空岛、砖砌镶边、珊瑚橙机器、琥珀树冠、微缩箱庭机位、
以及"方块即计量单位"的教学层）与 MC 分得开，所以可以接受；但这条张力是真实的，
**请你裁定**：

- **保持绿草**（当前）：像"草地"最直接。
- **改回暖色**：把 `grass_deep / grass_tip` 两个 uniform 改回暖金/琥珀（原草叶是 `#352509 → #FFA529`）。
  一处改动，不动几何与结构 —— 代价是顶面会偏"沙地"，要靠 `grass_side_band` 的断面维持"草"的读法。

另有一处可调的观感项：台面里的草皮斑现在是**绿色方块混在铺装里**，在近景读作小方格草皮。
若嫌碎，可以把 `PATCH_INNER_L4` 外推（只在更靠崖口的地方留斑）或调 `PATCH_THRESHOLD`。
