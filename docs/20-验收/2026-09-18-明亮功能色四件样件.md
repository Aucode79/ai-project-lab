# 明亮功能色四件 Godot 样件

四件静态样件用于检查已选明亮功能色、轮廓与倒角。它们没有替换游戏资产，没有接入运行事件或源码展开。

## 文件与入口

独立模块位于 `game/tests/bright_loop/`，不进入旧 28 件资产注册表：

| 文件 | 职责 |
|---|---|
| `bright_specimens.gd` | 构建循环台、记忆架、模型井、执行台；`build_machine(index, mono=false)` 返回 Node3D |
| `run_bright_loop_tests.gd` | 检查几何包络、网格、倒角、法线和材质 |
| `capture_bright_specimens.gd` | 固定正交机位、白色方向光与环境光；窗口捕获七个视图 |
| `measure_specimen_pixels.py` | 统计截图背景差异、色相区间和亮度分布；这是测量脚本，不是带阈值的通过/失败测试 |

依赖：`asset_node.gd` 提供 0.5 m 尺度；`sandbox_block.gd` 提供倒角网格拓扑。盒体数据取自 [浏览器样例](../10-契约/specs/2026-09-18-unfolding-study.html)。只按轴重映射顶点坐标，不非均匀缩放倒角；保留 0.05 m 内切及外延包络。

在仓库根运行：

```bash
tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path game \
  -s res://tests/bright_loop/run_bright_loop_tests.gd

tools/godot/Godot_v4.7.2-stable_win64_console.exe --path game --resolution 1600x1000 \
  -s res://tests/bright_loop/capture_bright_specimens.gd

python3 game/tests/bright_loop/measure_specimen_pixels.py \
  game/shots/art-upgrade/bright-loop/overview.png \
  game/shots/art-upgrade/bright-loop/mono.png
```

捕获必须使用窗口模式；脚本在 headless 下拒绝运行。截图写到 `game/shots/art-upgrade/bright-loop/`，包含 `loop / overview / top / mono / memory / model / execution.png`。输出位置固定，复跑会覆盖这些图。截图目录沿用仓库忽略规则。

## 验证记录

- 实施代理报告：构建器缺失时测试退出 1；实现后退出 0。
- 主代理独立复跑正确测试入口：`BRIGHT SPECIMENS TOTAL: 230 passed, 0 failed`，退出 0。
- 覆盖四件盒数、原尺寸、六面 0.25 m 落格、44 三角形倒角拓扑、0.05 m 内切点集、正面绕序、平面法线、无自发光材质及功能色色值。
- 窗口捕获由实施代理执行，报告修正一次不存在的 Environment 枚举后退出 0。主代理读取了总览、俯视与去色原图，三图均为 1600×1000。
- 总览中紫、蓝、黄、橙色族可区分；去色图中回路、梳齿、凹井与工作台轮廓仍不同。此为目视判断，不是用户辨识率实验。

## 尚未通过的产品验收

- 当前没有字砖文字、流向、运行状态与输入输出，因此不能宣称陌生用户能一眼读懂用途。
- 尚未实现 Godot 四层展开及逐行源码双向映射。
- 独立白底光照不能代表开放世界环境中的远距离可读性；未做沙盒接入、碰撞与交互验收。
- 230 条断言只覆盖此独立样件，不代表全仓测试通过。像素统计也不证明功能语义正确。
- 暂未将四件推广到其余组件，旧游戏入口与资产继续保留。
