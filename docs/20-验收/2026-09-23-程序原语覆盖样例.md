# 程序原语覆盖样例（设计门）

本表用于检查“Object / State / Transform / Router / Repeater + Channel + 递归 Group”能否承载不同类型代码，并且能否把函数子图真实嵌进父级三维结构。它是目标表示的设计样例，不代表当前 Python 导入器已经支持这些语法，也不是运行结果验收。

| # | 程序类型 | 最小 Python 样例 | 预期可视结构 | 需要保留的语义 |
|---:|---|---|---|---|
| 1 | 数值变换 | `def f(x): return x * 2 + 1` | `Object → Transform → Object` | 运算顺序、输入输出 |
| 2 | 命名状态 | `def f(x): y = x + 1; return y` | `Object → Transform → State(y) → Channel → Object` | 赋值与读取是同一个符号 |
| 3 | 列表聚合 | `def f(xs): return sum(xs)` | `Object(xs) → Transform(sum) → Object` | 聚合操作不能误画成重复执行，除非有循环证据 |
| 4 | 条件选择 | `def f(x): return 'big' if x > 3 else 'small'` | `Object → Router → 两条 Channel → Object` | 条件表达式与两分支 |
| 5 | 多路选择 | `def f(x):\n if x < 0: return -1\n if x == 0: return 0\n return 1` | 串接 Router 或多出口 Router | 分支优先顺序与提前返回 |
| 6 | 固定遍历 | `def f(xs):\n total = 0\n for x in xs: total += x\n return total` | `Repeater` 包住 `Transform`，连到 `State(total)` | 迭代源、循环体、累积状态、结束条件 |
| 7 | 条件循环 | `def f(n):\n while n > 0: n -= 1\n return n` | `Router/Repeater` 回边与退出 Channel | 条件在循环前检查及回边方向 |
| 8 | 函数组合 | `def f(x): return g(h(x))` | 嵌套 `Group(h)`、`Group(g)` 或串接 Transform | 调用顺序、参数与返回接口 |
| 9 | 递归 | `def fact(n):\n if n <= 1: return 1\n return n * fact(n - 1)` | `Group(fact)` 内部含 Router，并有回到自身的调用 Channel | 递归调用、基线条件、调用栈边界 |
| 10 | 对象状态更新 | `def f(state): state['count'] += 1; return state` | `State` 容器经 `Transform` 更新后输出 | 原地修改与新对象不能混淆 |
| 11 | 异常分支 | `def f(x):\n try: return 10 / x\n except ZeroDivisionError: return 0` | `Transform` 的成功/异常双通道进入 Router | 异常类型、捕获范围、错误路径 |
| 12 | 文件读写 | `def f(path):\n text = read(path)\n write(path, text)\n return text` | `Channel(file) → Transform(read) → State(text) → Transform(write)` | 外部副作用及读写对象身份 |
| 13 | HTTP 请求 | `def f(url):\n response = get(url)\n return response.status_code` | `Channel(network) → Group/Transform(request) → Transform(select status)` | 网络边界、请求参数、响应依赖 |
| 14 | 异步等待 | `async def f(client, q):\n response = await client.send(q)\n return response` | `Channel → Transform(send)`，等待点显示为同步屏障 | await 前后顺序与异步返回 |
| 15 | 事件回调 | `def on_click(event):\n return handle(event)` | `Channel(event) → Group(on_click) → Group(handle)` | 触发源与回调注册关系不能丢失 |
| 16 | 队列通信 | `def f(q, item):\n q.put(item)\n return q.get()` | `State(queue)` 与带方向的 `Channel`，写入/读取两个 Transform | FIFO 通道、阻塞/非阻塞属性 |
| 17 | Agent 工具循环 | `def run(task):\n tools = ["world.snapshot"]\n messages = [message("user", task)]\n action = model(messages, tools)\n while action["tool"] != "finish":\n  messages = messages + [message("assistant", action), message("user", dispatch(action, tools))]\n  action = model(messages, tools)\n return action["args"]["text"]` | `Group(Agent)`、`Router`、`Channel(tool/environment)`、`Repeater` | 观察→决策→工具→新观察闭环；`finish` 直接退出 |
| 18 | 类与实例 | `class Counter:\n def __init__(self): self.n = 0\n def inc(self): self.n += 1\ndef main():\n first = Counter(); alias = first\n alias.inc(); other = Counter()\n first.inc()\n return [first.n, alias.n, other.n]` | `Group(Counter)`、实例状态 `n`、方法调用盒 | 构造分配独立状态；别名共享状态；实例方法作用域 |
| 19 | 生成器管线 | `def f(xs):\n return (x * 2 for x in xs if x > 0)` | `Repeater` + `Router` + `Transform` 的惰性流 | 逐项产出，不得伪装成一次性列表 |
| 20 | 资源作用域 | `def f(path):\n with open(path) as file:\n  return file.read()` | `Group(resource scope)` 包住读操作，进入/退出 Channel | 资源获取、释放及异常退出时的清理 |

## 逐例记录栏

样例 18 追加验收：把初始化常量从 0 改成 3 后，编辑图再次编译执行两次，与修改后的原生 Python 一致，均返回 `[5, 5, 3]`。转换器拒绝会改变实例类型跟踪的条件/循环内重绑定、方法接收者重绑定、不完整初始化返回，以及源代码引用内部方法名。类级装配台造型、源码回溯交互和年龄段解释性仍未验收。

模块级常量回归：`LIMIT=3` 被入口及另一个函数引用时，导入图与原生 Python 对相同输入均返回 7；选中任一引用修改为 5 后，两个函数下次运行都使用新值，入口结果为 9。字符串标量常量可经 F2 修改；列表模块变量会按当前边界拒绝导入。

导入表达式补充：`0 < value < values[0] < 10` 转为比较节点与 `and` 短路关系；当首个比较为假且 `values` 为空时，原生 Python 与导入图都返回 `False`，不会提前读取下标。链式比较中的自定义函数和文件效果明确拒绝。
