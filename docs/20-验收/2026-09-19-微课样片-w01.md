## 二、画面语言（本轮定下来的口径）

- **主体是 HTML/CSS 动效，工坊 3D 只出插图**。26 件工坊件没有独立 tscn，外形真源是
  `component_catalog.gd` 的几何表；`capture.gd` 现按 id 现搭（`--margin` 放留白），
  `prep_plates.py` 裁掉透明边得到卡片插图。不给工坊件补 `asset.yaml`——那会撞
  `validate_assets.py` 的一一对账。
- **色板与造型跟着游戏走**：纸 #f7f0d8 / 墨 #263b40 / 行动橙 #ef743b / 信号青 #24b9cf /
  核心黄 #f2c43d（`asset_style.gd`）；卡片统一切一个 45° 角，呼应"裸露表面统一直切倒角"。
- **固定版式**（大纲 §7.2）：左上课号牌、右上进度条 + 段名、底部字幕条；镜 1 课题卡除外。
- **字幕逐字点亮跟配音走**：edge-tts `WordBoundary` 给词级时间戳，不靠估。
- **组件卡三态**（分镜稿手法 C）：卡 → 3D 件高亮 → 一句作用，例句连标点一起从左往右长出。

- 语速本身合规：`zh-CN-XiaoyiNeural` `+0%` 实测 **4.1 字/秒**，落在分镜稿"儿童向每秒 4–5 字"档内。
  差额来自**标点停顿**——分镜稿按字数估秒时没算逗号与句号的停顿（每句 3–5 处）。
- 分镜稿 §3.1 的处置口径是"超了就删字，不加快语速"。**删哪几个字归人定**，样片先把
  实测长度留在片里当证据；若改为整课放宽到 6 分钟，则 37 镜的秒位要整体重排。
- 外延：全片 37 镜若同样超 15%，5 分钟课会变成约 5 分 45 秒。

## 五、还没做到的

- **只做了 8 镜**：段3–段8（三轮运行、循环回放、失败分支、口诀收束）未开工，其中"能量线/行动牌/回执卡/俯视图回路"四类画面是新的动效元件，本样片没验证过。
- **配音只经手没经耳**：电平、时长、词级时间都是机器量；音色是否合 8–18 岁由人试听定（换声：`VOICE=zh-CN-XiaoxiaoNeural python3 tools/production/build_narration.py --episode w01`）。
- **工坊内的"这一件亮起"**：现在的高亮是 HTML 在透明插图后面加光晕，不是引擎里那件真发光。要真发光得给 `bright_workbench._capture_if_requested` 加 `--focus/--page` 机位覆写（与 `level_scene_base` 的 `--shot` 同一套旗标）。
- **已做到的角标**：「教学演示 · 预设动画」常驻课号牌下方（分镜稿 §6 要求，工坊还没有真
  实 Agent 运行事件源，这条不能省）。
- **重看锚点**：§4 三道练习的跳回时间点是按名义秒位写的（0:55 / 3:55 / 3:15），实测时间线整体后移约 15%，铺全片时要按实测秒位重算。
