## 一、成品架构（v12.14）

### 数据脊柱（全部入库，渲染可复现）
- `lesson01/narration.json`：24 段逐镜旁白（改台词必须删对应 `voice/*.wav` 再重跑配音，脚本按 id 跳过已有文件）
- `lesson01/run.json`：真实运行记录 r1790010445-001（24 次模型调用逐步入库，画面回放全部由它驱动）
- `lesson01/edit.json`：时间轴真源（镜起止/时长/事件时刻，由 prepare/finish 生成）
- `lesson01/alignment.json`：whisper 词级时间戳（音画同步与逐字字幕的锚）
- `lesson01/captions.ass`：字幕+课号牌+进度条+工具卡片（混流时烧录）

### 双场景渲染体系（`render_lesson_2d.py`，全 Manim）
- **ShotScene（运行段 12 镜）**：沙盘地图 + 概念联动条 + 事件驱动回放。每个事件（模型调用/工具执行/观测返回/封路）同时驱动地图动画和联动条状态。
- **ConceptScene（概念段 11 镜）**：s02 名牌、s03 派活、s12–s17 复盘循环图（逐站点亮→五环成圈）、s18 延续定格、s19 联动条+双任务、s20 对话框、s21 开盖收尾。s01 走一遍在 ShotScene 内做节拍化重放。

### 概念联动条（本课最重要的教学装置）
地图上方空带常驻四色块——**蓝·便签｜黄·大语言模型｜橙·工具｜蓝绿·观测**（与复盘循环图同色同源）+ 独立红色**环境**块：
- **方案 B 状态常亮**：待命 0.45 / 激活 1.0 / 刚干完 0.7，保持到下一阶段（红绿灯式，随时抬头可读，不靠抓瞬时脉冲）
- **方案 C 徽章驻留**：指令卡（查路/装货/卸货/移动）飞到工具块上方停驻，结果卡沿直角回程箭头（观测→下→左→上）走 1.75 秒（=平时 2.5 倍）落到便签块下方箭头头处；同文徽章去重（重复步骤不再演示）
- **环境块独立闪现**：封路时刻意不连任何箭头到模型块——「不是它干的」的视觉论证

### 音画同步（词级锚定）
`finish_lesson.py` 的 `PHRASE_ANCHORS` 把 12 个关键事件锚到"描述它的那句台词"的词时间戳（如「到了 B」→移动、「路被封住了」→封路），无锚事件在锚点间插值。实测 12 锚全部 ±0.05 秒。

## 四、坑位大全

### Manim（CE 0.21）
1. 帧数记账：所有播放统一走 play 路径 `run_time=(k-0.5)/25`，纯 wait 会截断漂移。
2. `CurvedArrow` 不认 `max_tip_length_to_length_ratio`（那是 Arrow 的）。
3. `ImageMobject` 不能进 `VGroup`（用 `Group`）。
4. 场景工厂（type() 批量生成）必须在类定义**之后**执行，否则 NameError。
5. **任何 `scene.play` 都会产帧**——绕过 play_ 记账的直调（如淡出旧徽章）会让段多出帧（second +5 帧实例）；空动画列表会崩（加 Advance 兜底）。
6. z_index 默认 0：卡会被 z=5 的箭头穿过（提到 8）。
7. `Advance(ValueTracker)` 自定义动画是把 idle 时间变得可数的标准手法。

### 管线
1. `voice_lesson.py` 按 id 跳过已有 wav——**改台词必须先删旧 wav**（本次 s18 裁句、8 处减裁均踩过设计而非坑）。
2. whisper `initial_prompt` 偶发幻听（著名频道片尾语）；兜底：<0.6 相似度去 prompt 重转写。
3. edit.json 镜时长 = 语音 + 停顿垫；事件时刻独立重排（词锚+推挤）；atempo 会按文字预算地板自动减速语音（s01 19.28→22.5s 实例）。
4. Git Bash 的 `/tmp` 是 MSYS 路径，Windows 版 ffmpeg concat 读不到——concat 清单用仓库内相对路径。
5. 混流必须切到 `lesson01/` 目录（ass 滤镜与输出名是相对路径）。
6. README 等文件是 CRLF：Edit 工具的多行锚点易失配——**patch 前先 grep 实文取准确锚**；补丁脚本 write_text 在末尾，中途断言失败=零写入（多次栽过）。

### 流程（最重要）
1. **像素级客观验收铁律**：缩进/事件循环类改动后，必须跑"货物像素 x 随时间曲线"验证动画真实发生且与台词同步——肉眼判帧两次误判（"半途"实为 A 点）。
2. **几何包围盒审计**：按渲染器常量复算全部元素包围盒对画框/相邻件求交——揪出 s17 名牌"出生即出画"这类目检永远找不到的问题。
3. 单文件补丁用"唯一单行锚"比多行锚可靠。
4. 样片先行：大改动（结尾选型）先出小样+上下文扩展版对比，再落正片。

## 五、验收方法（每版必过）
1. **帧数零误差**：24 段逐个 ffprobe，帧数 === round(duration×25)，总数 === edit.frames。
2. **像素曲线**：货物橙色像素中位 x 随时间（A≈468/B≈654/C≈746/D≈941 校准值）——验移动时长、起止时刻、与台词锚的先后。
3. **抽帧目检**：成片多点抽帧对照预期画面（仅在上述两项通过后做）。
4. **几何审计**（结构性改动时）：全元素包围盒复算。
