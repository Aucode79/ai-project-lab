## 实现边界

模块语义没有固定层数，但实际递归仍受 Python 栈与机器资源约束。模型请求最长 90 秒，取消在节点边界或当前请求返回后生效。

具名端口编辑以二维模块图为精编入口，三维整机展示根程序并支持端口直接拖线（见下方补完轮）；旧 26 件工坊组件未迁移为新程序节点（工坊保持资产浏览）。观察输入是结构化世界状态，不是相机图像。文档对象覆盖工作目录文件；UTF-8 文件可编辑，二进制文件只列出元数据。运行层输出与世界记录均是真实事件，测试替身仅用于编译语义回归，不计为真实任务成功。
