## 2. 本轮已改（4 处，都不损失信息）

1. **`player_screen` 的 Screen：PlaneMesh → 竖直方块面板。顺带修掉一个真 bug。**
   Godot 的 `PlaneMesh` 默认 `orientation = FACE_Y` —— 也就是**水平**的一片。实测它的 AABB 是
   `(3.6, 0, 2.025)`：厚度为 0，**2.025 那条边躺在 Z 上**，整片从边框前后穿出来。
   也就是说"视频幕布"一直是躺着的，且穿模。现在换成 `(3.6, 2.025, 0.06)` 的竖直盒，前脸仍在 z=0.07，
   标题与播放/暂停指示的相对位置不变。渲染复查：`A3/_zoom_player_screen.png`（幕布竖直、标题与暂停条都在面上）。
2. **`l2_scanner` 的 Beam：同样的朝向 bug + 换成方块。** 注释写"竖直光片"，实际也是水平的一片。
   现在换成 `(0.75, 1.0, 0.25)` 的半透明方块。
3. **`conc_thinker` 纸条 −12° → 0°**（纯装饰斜插，竖直插进纸口；信息量不变）。
4. **`mach_splitter` 分流板 ±45° → 0° / 90°**（两个状态照样一眼可辨：板面朝向差 90°）。

验证：`bash tools/run_tests.sh` → `PASS=25 FAIL=0 SKIP=0`（21 套 **307 条**断言，数目未变）。
渲染复查：`A3/blocks_op_sandbox.png`、`A3/blocks_l2.png`。

## 3. 剩余三类：已按同一口径全部改造（2026-09-16 第二轮）

| `Props/Tree_*` | **圆柱树干 + 4 个压扁的球冠**，每棵还带随机偏航 | **方块树**：0.5 整数倍的方块拼"树干 + 十字冠"；朝向只取 0/90/180/270 |
| `Props/Rock_*` | **球**，随机偏航 | **方块石**：两块错开搭的方块，朝向 0/90/180/270 |
| `conc_verify_gate` | 岔路地条 −28.6°、门体 −18°/78° | 地条沿 +Z（岔路收成直角）、门体 **0°/90°**（语义不变：通过=沿正路，拒绝=转向岔路） |

| `conc_tool_belt` 四个工具头 | **Prism / Cylinder / Torus**，而且被 `run_l4_tests` **三条断言钉死**（源码注释写着"形状类不动"） | **全部方块**：靠**块数**区分 读=1 / 写=2 / 跑=3 / 搜=4；那三条断言已同步改写为"块数断言 + Head 下全是 BoxMesh" |

> **关于推翻那条测试锁**：`run_l4_tests` 原来断言四个工具头必须是 Prism/Cylinder/Torus，

> 它挡的正是"资产一律由方块组成"这条口径。新断言比旧断言更强 ——
> 它同时要求"Head 下全是 BoxMesh"且"块数 1/2/3/4 各不相同"。
